Notions clés

Phase stationnaire apolaire

La silice est greffée de chaînes octadécyle (C18). Les composés les moins polaires s'y attardent : ils sortent en dernier.

Facteur de rétention

k = (tR − t₀) / t₀

t₀ est le temps mort, celui d'une molécule non retenue. k ne dépend pas du débit.

Efficacité

N = 5,54 · (tR / δ)²

δ est la largeur à mi-hauteur. Plus N est grand, plus les pics sont fins. N augmente avec la longueur de colonne.

Résolution

Rs = 2 (tR2 − tR1) / (ω₁ + ω₂)

ω est la largeur à la base. Deux pics sont séparés à la ligne de base quand Rs ≥ 1,5.
